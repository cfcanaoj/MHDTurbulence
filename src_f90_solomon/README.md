## Solomon-based implementation

The code in `src_f90_solomon` is based on the Fortran version of
[Solomon](https://github.com/ymiki-repo/solomon/tree/fortran),
originally developed by Yohei Miki.

The initial copy was taken from
[Solomon commit `46c245f2`](https://github.com/ymiki-repo/solomon/commit/46c245f2aed95a7ff94b9e870f36448e2d42c246).
The code has subsequently been modified for use with MHDTurbulence.
